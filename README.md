# Projeto---Como-organizar-sua-vida-Financeira-com-Planilhas-Inteligentes-e-IA
Planilha de Dados – Vida Financeira 🌌
📒 Descrição
Esta planilha tem por finalidade a organização da vida financeira.
🤖 Tecnologias Utilizadas
•	Ferramenta Excel para edição.
🧐 Processo de Criação
Utilizei o "Excel" para mapeamento dos dados, consolidação e retratação em forma de gráfico para facilitar a compreensão de forma visualmente simples.
🚀 Resultados
A planilha de dados permite a compilação da vida financeira de forma a mapear as entradas, saídas e reserva de recurso.
💭 Reflexão
Criar esta planilha demonstra como as ferramentas podem contribuir para gestão diária da vida financeira, seja pessoal ou de uma empresa.
